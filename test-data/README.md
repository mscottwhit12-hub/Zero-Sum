# Test data

Not bundled into installs and not seeded. Used by test runs.

- `packs/catan-risk.json`: library pack for the simulated test night. Import it via GM → Library → Import pack.
  - Default lengths are planning values only. Gold always uses the hours entered at the result.
  - Catan: 1.5 h, the midpoint of the published 60–120 min.
  - Risk: 4 h, within the published 1–8 h.
